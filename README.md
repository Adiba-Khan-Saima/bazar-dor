# বাজার দর | BazarDor

BazarDor is a responsive web application for checking the latest prices of daily essential products in Bangladesh.

## Features

- View today's prices of essential products
- See products whose prices increased or decreased
- Browse products by category
- Sort products by price
- View detailed product information and market-wise prices
- Email and Password authentication
- Google and GitHub login
- User profile and update information
- Responsive design for mobile, tablet, and desktop
- Friendly 404 page

## Technologies Used

- Next.js
- React
- Tailwind CSS
- Better Auth
- MongoDB
- Lucide React
- React Hot Toast
